# Phase 10.3 / 10.4 — Centralized Home & Social-ready Navigation

## Status
10.3 delivered; 10.4 foundation added.

## Product UX
- Mobile-first centralized Home screen.
- Profile/identity summary and coins at the top.
- Primary Play Online action.
- Private Room entry with 6-digit room code.
- Match History entry.
- Clear server connection state.
- Social/rewards/shop destinations reserved for their dedicated production phases.
- Game table remains isolated from home navigation so future screens can be added without changing the game engine.

## 10.4 foundation
- Navigation destination model for Friends, Daily Rewards, Shop and Leaderboard.
- These destinations are intentionally not fake implementations: their production data flows will be connected in Phases 11–14.

## Acceptance
- Home remains usable on portrait phones and desktop.
- Existing authenticated multiplayer flow is preserved.
- No mock friends, rewards, shop balances or leaderboard values are presented as real data.
